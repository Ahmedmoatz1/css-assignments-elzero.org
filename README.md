# 🎨 CSS Assignments – Elzero Web School

This repository contains my solutions to the **CSS assignments from Elzero Web School**.  
Each task is organized in a clean structure for easy navigation and practice.

---

## 📂 Project Structure
The assignments are divided into folders based on their category/level.  
Inside each folder, you'll find the **HTML & CSS files** for the task.

```
css-assignments-elzero.org/
│── 01-selectors/
│── 02-colors-background/
│── 03-typography/
│── 04-box-model/
│── ...
└── index.html
```

## 🚀 Features
- ✅ Covers all CSS assignment topics step by step  
- ✅ Clean folder structure for better organization  
- ✅ Uses modern CSS techniques and best practices
